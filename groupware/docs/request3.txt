요청
0. 아래 작성하는 내용은 html과 spring의 thymleaf를 사용해서 작성해줘.

1. resources/templates/module 디렉터리를 만들고 그 안에 menubar.html을 작성해줘.
메뉴바를 구성하는 화면을 만들되, 화면 좌측에 고정 시켜서 다른 html에서 사용하게 할거야. 
메뉴를 넣은 버튼 4개를 미리 만들어줘. 화면에 보이는 버튼이름은 예시1, 예시2 패턴으로 작성해줘.
디자인은 네모 바를 만들되, 모던하고 정리된 느낌으로 재구성해줘.
css를 적용 시켜서 작성하되, css 파일은 resources/static/css 하위에 작성해줘.

2. resources/templates/module 디렉터리 하위에 상단정보(이름은 자체적으로 작성해줘).html을 작성해줘
최 상단에 "사내 메신저" 라는 문구로 사이트 제목을 달아주고, 사이트 제목 에서 20px 정도 떨어진 우측 하단에 로그인 버튼을 만들어줘.
버튼에 동작은 넣지 않아.
css를 적용 시켜서 작성하되, css 파일은 resources/static/css 하위에 작성해줘.

3. resources/templates 하위에 home.html을 작성해줘
1,2번 항목에서 작성한 html 파일들을 적용할 수 있도록 설정해줘.
화면은 menubar.html 우측에 출력 되도록 해주고, 정 가운데에 "사내 메신저 메인" 이라는 이름을 출력하게 해줘.

4. 전체 화면 구성은 structor.png를 참고해서 구조만 적용해줘. 
5. 사이트의 전체 색상은 남색을 기준으로 검정색과 흰색을 사용해서 CSS에 작성해줘.
6. 작업이 완료되면 빌드하지 말고 어떠한 git 작업도 하지 말고 나한테 말해줘.
